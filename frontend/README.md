# Frontend

## Funzionalità principali

- **Registrazione**: Tramite la pagina /register permette all'utente di registrarsi sulla piattaforma inserendo i propri dati.
- **Login**: Permette all'utente di accedere inserendo email e password.
- **Dashboard**: La dashboard è la pagina che viene visualizzata dopo il login, dove compare un messaggio di benvenuto con il nome e cognome dell'utente che ha effettuato il Login. In questa pagina verranno visualizzati anche tutti i post dei vari utenti.
- **Navbar**: La navbar permette all'utente di spostarsi tra le varie pagine del sito e di scegliere la lingua del sito tra Italiano e Inglese.
- **Creazione Post**: Permette all'utente di creare vari post. Questi possono essere successivamente eliminati dallo stesso utente.
- **Creazione Commenti**: Permette all'utente di creare dei commenti sotto i post. Questi possono essere successivamente eliminati dallo stesso utente.
- **'Profilo Personale**: Tramite la pagina /Profile si entra nel profilo personale dell'utente loggato, dove è possibile vedere i propri post e crearne altri. In questa pagina è possibile modificare i propri dati personali.
- **Pagina Users**: Nella pagina /Users è possibile visualizzare la lista dei vari utenti registrati nella pagina e da lì è possibile accedervi.
- **Profili Utenti**: Nei profili degli utenti, è possibile visualizzare i dati personali degli utenti e i loro post.
- **Interfaccia reattiva**: Ottimizzata per dispositivi desktop e mobili.
- **Integrazione API**: Comunica con il backend per ottenere e aggiornare i dati in tempo reale.

## Requisiti

- Node.js (versione 14 o superiore)
- Angular CLI (versione 12 o superiore)
- Browser moderno (Chrome, Firefox, Edge)

## Installazione

1. Clona il repository:
   ```bash
   git clone https://github.com/aldosimone99/CityLife2.git
   cd CityLife2/frontend
   ```

2. Installa le dipendenze:
   ```bash
   npm install
   ```

3. Avvia l'applicazione in modalità sviluppo:
   ```bash
   ng serve
   ```

4. Apri il browser e visita [http://localhost:4200](http://localhost:4200).

## Struttura del progetto

- **src/app**: Contiene i componenti Angular principali.
- **src/assets**: Include risorse statiche come immagini e file CSS.
